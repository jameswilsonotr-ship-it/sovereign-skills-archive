# Android scaffold placeholder

This directory is intentionally not an Android application.

The future app export should provide the Gradle wrapper, root Gradle settings,
an `app/` module, an application ID, manifest, source, resources, and tested
debug/release build tasks. Do not vendor an AI Studio export, generated APK,
keystore, API key, Play service-account JSON, or other build secret here.

Until a real Android module is added, use
[`docs/AI_STUDIO_PLAY_PATH.md`](../docs/AI_STUDIO_PLAY_PATH.md) and run the
manual workflow stub only to validate the documentation scaffold.
