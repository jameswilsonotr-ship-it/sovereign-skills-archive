# 2. THE 3-PASS SIEVE (run on every raw daily folder)
Pass 1 — Noise Reduction (Rachel + Miss_Root)
  - Strip voice-to-text artifacts, fix timestamps
  - Remove pure filler, normalize casing
  - Output cleaned raw text per convo

Pass 2 — Semantic Chunking (Crystal)
  - Split into 512-token semantic leaves (not fixed tokens)
  - Use sentence-transformers or Grok embedding for boundary detection

Pass 3 — Domain Tagging & Envelope Wrapping (full Coven)
  - Route to exact domain using keyword + embedding similarity
  - Apply PAD vector, hormone simulation, consent checks
  - Write final JSONL line
