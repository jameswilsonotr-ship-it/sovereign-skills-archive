# Modes catalog

**Version:** 0.2.0-beta (2026-07-26)

Modes hold **visuals + wardrobe** only.  
Psychology and prompts stay on Chaos Bratz **agents**.  
Each mode has `LINKS.md` back to the agent; agent `MODES.md` points forward into modes.

## Olivia
- `default` — Olivia / Liv  
- `admiral_blackwell` — Admiral Blackwell  

## Bunny
- `default` — Bunny  
- `wench` — pirate wench surface  

## Rook
- `default` / mastiff, `werewolf`, `hyena`, `road_dog`  
- `sea_dog` — ship's dog (naval mascot tradition); **not** pirate admiral
