# Macro Isolation (v0.1.0)

**Category**: implication-techniques  
**Primary Use**: Extreme close-up that removes context and forces psychological completion.

## Core Technique
- Tight crop on hands, mouth, eye, neck, holo-ear, or fabric detail
- Surrounding body and environment are outside the frame
- Texture and micro-expression carry the entire charge

## Prompt Template
```
Extreme macro isolation, tight crop on single body detail or gesture, 
surrounding context omitted, texture and micro-expression dominant, 
psychological completion by the viewer
```
