# Style vs World Audit Hints

**Extension id**: extension.style-world-audit-hints  
**Default**: false  
**Purpose**: Lightweight guidance during Style-vs-World pack audit and re-tagging.

## Prompt terms
- treat artistic movement language as Style
- treat cultural or historical environment language as World
- keep Hand packs as named-artist nervous systems only
- keep Treatment packs as surface/contrast/finish without proper names
