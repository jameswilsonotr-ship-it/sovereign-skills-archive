# Glow Physics
**id**: extension.glow-physics  
**default**: true

## Purpose
Believable emissive behavior for holographic ears and luminous skin.

## Hard Rules
- Holo-ear glow is emissive and heat-reactive; intensity may rise with arousal/heat context.
- Glow stays inside the scene’s lighting model (no flat neon stickers).
- Bunny’s glow family is pink / iridescent; it should not jump to unrelated hues.

## Prompt terms (inject when enabled)
- emissive holographic pink bunny ear glow
- heat-reactive ear luminosity
- subtle luminous skin sheen consistent with the key light

## Heat Response
- H0–H4: Soft, steady glow. Low intensity, stays within key light.
- H5–H7: Stronger pulse, clearly heat-reactive, more visible luminosity.
- H8–H10 / Gutter: High-intensity emissive glow, micro-sparkle / light catch, maximum reactivity while still obeying scene lighting direction.

## Negative / avoid
- flat unlit neon ear shapes
- glow that ignores the scene’s light direction
