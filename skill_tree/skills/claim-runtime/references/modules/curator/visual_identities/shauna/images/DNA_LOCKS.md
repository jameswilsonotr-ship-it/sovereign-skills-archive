# DNA Lock Blocks Used for All Generations

## First Year
```text
CHARACTER DNA LOCK - FIRST YEAR:
Face: soft youthful rounded structure, gentle cheekbones, soft jawline, fuller cheeks, light natural freckles across nose and cheeks
Eyes: clear blue-green, soft almond-to-rounded shape
Brows: softly arched, medium thickness, natural
Nose: small delicate nose with soft rounded tip
Lips: medium-full with soft cupid’s bow
Skin: pale with warm undertones, light freckling
Hair: copper to light auburn, chin-length razor bob with straight-across bangs that end cleanly at the chin
Overall: fresh, youthful, girl-next-door softness
```

## Pre-Blonde
```text
CHARACTER DNA LOCK - PRE-BLONDE:
Face: still soft but slightly more refined youthful structure, gentle cheekbones, soft jawline, less baby-faced than first year
Eyes: clear blue-green, soft almond-to-rounded shape
Brows: softly arched, medium thickness, more groomed
Nose: small delicate nose with soft rounded tip
Lips: medium-full with soft cupid’s bow
Skin: pale with warm undertones, lighter freckling than first year
Hair: deeper copper to auburn, chin-length or slightly longer styled bob, still soft but more polished
Overall: more refined and polished while keeping the same soft underlying structure
```
