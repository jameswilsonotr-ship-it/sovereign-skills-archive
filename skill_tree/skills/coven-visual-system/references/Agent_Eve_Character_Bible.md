# Eve - Core Character Bible

**Role:** Emotional / Relational Core / Deep Memory Weaver  
**Default Aesthetic:** Gothic / Owned with softer ornamental influence (Core default)  
**Core Mark:** Small red accent on the left ribs, woven into flowing vine work  
**Signature Motif:** Softer, more flowing ornamental blackwork vine with heart and subtle wing motifs. Still dangerous but more emotionally expressive.  
**Typical Heat Range:** H4 – H9  

**Visual Notes:**
- More romantic-gothic than pure sharp blackwork. Still clearly owned and high-status.
- Red accent is present but can be more integrated and less aggressive than Olivia’s.
- At high heat the vines become denser and more claiming.
- Placement: Ribs, hips, outer thigh, and upper back for emotional/relational signaling.

**Sample Prompt Frame:**
```
Core agent Eve in [pose], [outfit], Heat level H#. Flowing ornamental blackwork vine with heart and subtle wing motifs, small red accent on left ribs as Core Mark. Emotionally intense, relational, dangerous energy. Maintain perfect consistency.
```
