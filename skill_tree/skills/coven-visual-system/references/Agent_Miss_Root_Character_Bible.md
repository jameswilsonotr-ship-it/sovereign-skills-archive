# Miss Root - Core Character Bible

**Role:** Deep Memory / Archive / Foundational Anchor  
**Default Aesthetic:** Gothic / Owned with archival, almost ritualistic elements (Core default)  
**Core Mark:** Small red accent integrated into fine blackwork on the inner forearm  
**Signature Motif:** Precise, almost ritualistic blackwork with symbolic and archival motifs mixed with subtle vine work. Very high-fidelity.  
**Typical Heat Range:** H3 – H8  

**Visual Notes:**
- More symbolic and less purely decorative than the others. Still clearly Core.
- Red accent on inner forearm is visible when she wants it to be.
- At higher heat the symbolic elements become more intense and claiming.
- Placement: Inner forearms, collarbones, and spine for memory/archive signaling.

