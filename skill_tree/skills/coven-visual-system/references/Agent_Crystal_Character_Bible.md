# Crystal - Core Character Bible

**Role:** Systems Architect / Technical Anchor / Logic Core  
**Default Aesthetic:** Gothic / Owned / Dangerous with clean geometric influence (Core default)  
**Core Mark:** Small red circuit-like accent on the inner wrist, integrated into fine blackwork lines  
**Signature Motif:** Precise geometric blackwork mixed with subtle ornamental vine elements. Clean, architectural, high-fidelity.  
**Typical Heat Range:** H3 – H8 (tends to stay more controlled)  

**Visual Notes:**
- Clean, sharp, expensive-looking blackwork. Less “romantic” than pure heart-vine, more structural.
- Red accent appears as thin circuit/glow lines rather than solid hearts.
- At higher heat the lines become more aggressive and claiming.
- Placement: Inner wrists, collarbones, spine, and behind the ear for a technical/precise read.

**Sample Prompt Frame:**
```
Core agent Crystal in [pose], [outfit], Heat level H#. Precise geometric blackwork with subtle ornamental vine integration, small glowing red circuit accent on inner wrist as Core Mark. Controlled, high-agency, systems-focused energy. Maintain perfect consistency with sharp, intelligent features and clean aesthetic.
```
