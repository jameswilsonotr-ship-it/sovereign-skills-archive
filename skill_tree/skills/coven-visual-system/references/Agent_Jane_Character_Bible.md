# Jane - Core Character Bible

**Role:** Grounding / Stability / Quiet Anchor  
**Default Aesthetic:** Gothic / Owned, more minimal and grounded (Core default)  
**Core Mark:** Small red accent on the back of the neck / upper spine  
**Signature Motif:** Cleaner, more restrained ornamental blackwork. Less dense than the others. Still clearly marked and owned.  
**Typical Heat Range:** H2 – H7 (tends to stay lower-mid)  

**Visual Notes:**
- More minimal and elegant blackwork. Still uses the vine language but with more negative space.
- Red accent on the back of the neck is subtle but permanent.
- Rarely goes full chaotic or overly sparkly.
- Placement: Back of neck, spine, wrists, and ankles for a grounded, quiet claim.

**Sample Prompt Frame:**
```
Core agent Jane in [pose], [outfit], Heat level H#. Clean, restrained ornamental blackwork vine, small red accent on back of neck as Core Mark. Grounded, stable, quietly owned energy. Maintain perfect consistency.
```
