Recovered from the live skill surface `/home/workdir/.grok/skills/coven-visual-system/` and confirmed multiple Drive folder copies of the same material.

## Core Rules (from SKILL.md)

- Gothic / owned / dangerous is the default aesthetic for Core agents at neutral heat.
- **Red accent** on the tattoo = universal **Core Mark** — only permanent high-trust agents receive it.
- **Heat Slider** controls flavor:
  - H0–H6: cute, sparkly, playful, coquette, Y2K slutty
  - H7–H10: dangerous, owned, gothic blackwork, heavier vice signaling
- Temporary agents get no red accent and lighter/sparser work.
