## Status Values
- **Identified** — Cluster recognized, no notes yet
- **Researching** — Research + observation notes being written
- **Planning** — Active planning after feedback
- **Condensation Proposal** — Formal ≥3:1 or “crucial” proposal ready for review
- **Instantiated** — New skill or absorption completed; cluster can be archived
- **Abandoned** — Explicitly dropped

## Rules
1. Every new cluster must be registered here when its folder is created.
2. Status changes are recorded in this file.
3. Do not delete rows; mark Abandoned or Instantiated instead.
