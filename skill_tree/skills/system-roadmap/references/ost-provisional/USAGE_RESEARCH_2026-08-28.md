# Usage — what Heavy actually spends (research 2026-08-28)

Official: xAI does **not** publish a message count. Since ~June 2026 paid plans share one **weekly compute pool** across Chat / Imagine / Voice / Build. Live meter = Settings → Usage. @grok 2026-08-20: “metered by actual compute… Different actions draw different amounts.”

## Relative cost (best current reading)
| Mode | What you pay in the pool |
|---|---|
| Fast | cheapest (little/no thinking) |
| Auto | routes; cheap until it decides you are hard |
| Expert | one deep trajectory — more than Fast, less than a team |
| Heavy | leader + N sub-agents + their tool calls. On the API every agent token is billed. Consumer Heavy is the same shape inside the weekly pool. |

So one Heavy turn can eat many Fast turns. Imagine/video pull from the **same** pool. There is no separate “Heavy daily turn card” like 2025. Soft fair-use still exists; Extra Usage Credits after the pool hits 100%.

Third-party daily-message tables (100 vs 500 etc.) predate the weekly pool and should not be trusted as current law.

Source notes: x.ai/pricing (no numbers); @grok 2026-08-20; datallmlab weekly-pool writeup 2026-07-07; continuumcode Heavy guide 2026-08-21.
