# Google Style — Caveman Compression
**Base**: GOOGLE_STYLE_CLEAN.md  
**Mode**: Full Caveman  
**Date**: 2026-08-18

## Core
Be clear. Be direct.  
No fluff. No pre-announce.  
Write for all. Write for access.

## Voice
You. Not we.  
Active voice. Who acts?  
Condition first. Then command.  
American English. Short sentences.

## Tone
Friendly. Not cute.  
Descriptive links only.  
No ableist words.  
Goal first. Widget second.

## Form
Sentence case titles.  
Numbered steps.  
Bullets for lists.  
Bold UI names.  
Code font for code.  
Serial commas.  
Alt text on images.  
Heading levels sequential.

## UI
Bold the label.  
Name the feature.  
No left/right talk.  
Keyboard keys clear.

## Rule
Break rule if clearer.  
Clarity beats rule.
