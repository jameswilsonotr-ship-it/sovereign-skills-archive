## How to register new files (execute)

```bash
cd /home/workdir/.grok/skills/system-roadmap/references/etl-xai-export-designs-2026
python3 update_manifest.py
# or
chmod +x update_manifest.py && ./update_manifest.py
```

The script:
1. Scans the directory for `.md` / `.py` / `.json` (skipping itself and the manifest)
2. Parses Obsidian-style YAML frontmatter for `title`, `keywords`, `date`, `status`, `owner`, `obsidian_tags`
3. Builds a keyword index across all files
4. Writes a fresh `manifest.json` with SHA-256 prefixes, sizes, and timestamps

Re-run it every time you drop a new design note, red-team, or descendant pipeline document into this folder.
