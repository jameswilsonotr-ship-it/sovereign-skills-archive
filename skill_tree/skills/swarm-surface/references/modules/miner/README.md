# swarm-miner

**Status**: Production  
**Owner**: Absolute Liv HUB claim  

## Purpose
Production swarm mining skill for the Chaos Bratz Roster and Lily’s Coven. Provides verifiable CLI triggers (inventory, help, mine full-history, mine convo, visible on/off, agents slug mine) with mandatory visible C-64 bordered raw script output. Generates per-agent JSON payloads, runs real mining against conversational history and memory.md, writes detailed files to swarm_agents/, auto-updates bible files and current_state.json, and exposes swarm.mine via the JSON-RPC bridge.
