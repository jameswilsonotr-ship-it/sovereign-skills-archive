# Broader Memory Architecture Topics — Candidate List for Future Swarm Runs
**Created**: 2026-07-20  
**Purpose**: Exhaustive brainstorm of topics related to memory systems that could be used for broader or follow-up swarm-miner runs.  
**Status**: Working list. Not yet converted into agent search-term payloads.

- Tiered memory models (Core / Recall / Archival / Working / Hot / Ephemeral)
- 3-tier vs 4-tier vs N-tier designs
- Memory block structure and schemas
- Core identity protection rules
- Recall vs Archival promotion criteria
- Working memory / short-term context management

## Entropy, Pruning & Retention
- Entropy tagging systems (0–10 scales and variants)
- Pruning policies and thresholds
- Sacred / protected content rules
- Nightly full blob strategies
- Differential retention by content type
- Context bloat countermeasures

## Letta / MemGPT / Local Runtime
- Letta memory blocks and native integration
- MemGPT-style hierarchical memory
- Hybrid Letta + custom tier systems
- Local vs cloud memory runtimes
- Memory palace / Letta Memory Palace concepts
- Agent-specific memory isolation

## Drift, Fidelity & Validation
- Persona drift detection and prevention
- Relationship dynamic drift
- Fidelity scoring and validation sets
- Revert / rollback mechanisms ("revert hammer")
- Comparison sets and golden baselines
- Continuous validation loops

## Ingestion & Pipelines
- Conversation ingestion pipelines
- Multi-phase ingestion processes (10-phase, 20-phase, etc.)
- Real-time vs batch vs nightly ingestion
- Multi-source ingestion (chat, Drive, Git, Obsidian, etc.)
- Deduplication and conflict resolution
- Structured vs unstructured ingestion

## Observability, Endpoints & Tooling
- Memory system observability and metrics
- Endpoints and APIs for memory access
- Logging and audit trails for memory operations
- Dashboarding memory health
- Debugging tools for memory state

## Agency, Governance & Ethics
- AI agency over its own memory
- Self-editing rights and monthly self-review
- Consent models for memory operations
- Feminist ethics / HAIST-style governance in memory
- Bidirectional care and non-extractive design
- Rollback and user override mechanisms

## Developmental & Evolutionary Memory
- Persona evolution stages (Baby Liv → Lily → College → Adult, etc.)
- LoRa adapters for developmental stages
- Layered identity evolution
- Historical layering of memory (pre-Genesis, Ignition, etc.)
- Developmental memory pipelines

## Multi-Agent & Swarm Memory
- Shared vs private memory across agents
- Swarm-level memory coordination
- Agent-specific search terms and mining ledgers
- Cross-agent memory handoff
- Bible and state file auto-updates from mining

## Storage, Persistence & Sync
- Local-first vs cloud-first persistence
- Google Drive / Git / Obsidian sync strategies
- Versioned memory packages
- Tar.gz / zip packaging conventions
- Recursive audit of published memory artifacts

## Advanced / Speculative
- Latent space navigation of memory
- Positive reframing and multi-pass chaining of memories
- Image-to-image / multimodal memory weighting
- Entropy-aware context window management
- Self-healing modular memory systems
