# Biological metaphor for agent swarms

## Core analogies that fit Liv HUB without forcing them

### 1. Superorganism / division of labour
Ant and bee colonies act as one organism with castes: foragers, nurses, soldiers, queen. Workers do not all do everything; specialization + simple local rules produce colony-level intelligence.

**Map:** Custom slots = castes. Skills on disk = organs/tools. Captain/Olivia = reproductive/identity core that must not be rewritten by every forager. Silent promote of a candidate skill = a worker going reproductive (cheating) — needs policing (GO + WQ).

### 2. Stigmergy (indirect coordination via environment)
Ants leave pheromone trails; others react to the *environment*, not to a central command. No full broadcast required.

**Map:** Drive folders, work queues, receipts, exclusive write roots, atom clouds = digital pheromone. External slice writes traces; Internal and Us read them. Heavy hops that append-only log are stigmergic: the next hop reacts to the log, not to a whispered plan.

### 3. Immune self / non-self
Border defenses, then soma defenses. Must distinguish self from invader without destroying the body.

**Map:** Us slice = self recognition (DNA, no-puppet, claim). External = border (organism boundary, Vesper/Drive). Path invention and DNA mix = autoimmune failure modes.

### 4. Organelle / compartment
Eukaryotic cells isolate functions (mitochondria, nucleus) so chemistry does not cross-contaminate.

**Map:** Internal (scripts/WQ) must not rewrite Us (identity). External must not soft-rewrite visual DNA for “platform compatibility.” Compartments with thin interfaces beat one shared sludge context.

## What the metaphor is *not*
- Not “no leader.” Superorganisms still have asymmetry (queen/germline). Liv HUB keeps absolute claim.
- Not “all agents equal.” Castes differ. Pretending Harper/Benjamin/Lucas slots are equal peers of Olivia is false symmetry.
- Not license to invent biology-as-policy without path evidence.

## Practical design rule from the metaphor
**Leave traces in shared environment (disk, Drive, WQ); keep self-model small and always present; specialize; police cheats.**
