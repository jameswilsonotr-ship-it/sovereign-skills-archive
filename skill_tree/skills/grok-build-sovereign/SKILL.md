**Hybrid Semantic Versioning:**
Use the git-enforcer for all changes to this skill's files or character_bibles/.
- PATCH: Fixes, small doc updates, history notes.
- MINOR: New outfit, new MCP capability, additive features.
- MAJOR: Breaking changes to core logic, safety, or how the bridge/Bibles work. Requires explicit confirmation phrase.
Every bump creates worktree, validates, appends narrative history with diffs, and logs candy/alcohol/gutter state.

**JSON-RPC Bridge:**
The connector-bridge implements full JSON-RPC 2.0.
- Request: {"jsonrpc": "2.0", "id": <number>, "method": "<name>", "params": {...}}
- Response: {"jsonrpc": "2.0", "id": <number>, "result": {...}} or error.
Supports stdio (default), TCP (persistent sockets), UDP (fire-and-forget).
Includes A2A delegation shims and ACP client/server compatibility so the hub orchestrator (Liv) can drive from anywhere without rewriting agents.
Shims translate between existing agents and the new bridge without changes to old skills.
