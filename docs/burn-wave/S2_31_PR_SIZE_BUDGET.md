# S2-31 PR Size Budget

These are soft review budgets for small, focused pull requests. They are
guidance, not CI gates; explain any exception in the PR description.

| PR type | Maximum files changed | Maximum changed lines |
| --- | ---: | ---: |
| Docs-only | 3 | 200 |
| Test-only | 5 | 300 |

Count added and deleted lines across the PR. Keep a change within one row
unless the PR description explains why the scope crosses rows.
